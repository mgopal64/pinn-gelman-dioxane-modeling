# pinn-gelman-dioxane-modeling
Implementing a Physics-Informed Neural Network (PINN) to model 1,4-Dioxane migration in the Gelman Plume. By embedding the Advection-Dispersion Equation into a Deep Learning framework, this study bridges "data deserts" in the 130-170ft aquifer unit to forecast 100-year safety horizons for the Huron River. Pure PyTorch implementation.
